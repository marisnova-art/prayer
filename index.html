자동 스크롤

소리 내어 기도하면 1분에 250~300자, 눈으로 읽으면 400자 안팎이 알맞습니다. 스크롤 중에 화면을 직접 움직이면 잠시 멈췄다가 이어 가고, 본문을 한 번 누르면 멈춤·재개합니다. 자동 스크롤 중에는 화면이 꺼지지 않습니다(지원하는 브라우저).

오늘의 말씀

번역
고르는 범위
바뀌는 주기

현대어는 개역한글을 오늘의 말로 옮긴 Open Korean Bible(기완, CC BY 4.0)을 씁니다. 아직 현대어로 옮겨지지 않은 곳(시편·잠언·이사야 등)이나 말투가 지나치게 가벼운 곳은 개역한글로 보여 줍니다. 성경 본문은 파일에 들어 있지 않고, 그날의 말씀이 속한 책 한 권만 내려받아 이 브라우저에 보관합니다.

배경

폴더 안의 이미지 이름을 1.jpg, 2.jpg, 3.jpg처럼 번호로 붙이면 몇 장이든 자동으로 찾아 무작위로 보여 줍니다. 01.jpg 형식과 jpg, jpeg, png, webp, avif를 지원하고, 중간 번호가 두 개까지 비어 있어도 괜찮습니다. 웹 서버가 폴더 목록을 제공하면 파일 이름과 관계없이 모두 찾습니다. HTML과 같은 폴더를 쓰려면 ./ 을 입력하세요.

선택한 이미지는 배경에 맞는 크기로 줄여 이 브라우저에 보관합니다. 파일 이름 규칙 없이 쓸 수 있고, 원본 파일은 바뀌지 않습니다.
